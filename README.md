# 🎵 Buscador de canciones y biografía

Aplicación web desarrollada con **React** y **Vite** para consultar y visualizar
información relacionada con canciones y artistas.

Este proyecto fue realizado como parte del aprendizaje del docente **Jonathan MirCha**,
con el objetivo de practicar el consumo de múltiples **APIs** en un mismo formulario.

## 🚀 Tecnologías utilizadas

- React
- Vite
- JavaScript
- CSS
- React Router
- APIs (JSON Server)

## 📦 Instalación

```bash
git clone https://github.com/usuario/proyecto.git
npm install
npm run dev
```
